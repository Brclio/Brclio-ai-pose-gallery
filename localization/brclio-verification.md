# Brclio 样式改版核查

日期：2026-10-29。基准：首次公开发布提交 `24de4d3`。

## 设计依据

使用 Brclio Design System 的 `assets/template-app.html` 作为视觉起点，沿用品牌变量、紧凑导航、输入框、图库及弹窗模式。结合组件 1C 标签卡片、14 筛选栏、16 详情弹窗、36 缩略图与侧栏、12A 说明列表，适配现有图库结构。

布局由紧凑页头、横向分类与吸顶工具栏、自适应图片网格、大图与详情分栏组成。采用暖底、品牌蓝、黄色状态提示及少量红色；标题使用本地衬线字体，正文使用本地无衬线字体。无在线字体、图片滤镜、玻璃模糊、渐变标题、滚动入场或循环动画。尊重减少动态效果偏好。

品牌署名和许可记录在 CSS 注释及 README；未添加推广内容、账号链接或新的页面文案。App 场景优先于通用 P1 的超大标题、Scroll Reveal 和装饰性深色面板。

## 内容及行为保护

- 去除 `<style>` 后，`src/template.html` 与基准逐字相同。
- `src/app.js`、三份翻译文件和 `src/original.css` 与基准逐字相同。
- 所有图片均保持原始字节；图库记录、使用说明、ID、下载文件名未改动。
- 新样式独立位于 `src/brclio.css`，构建内嵌在原始样式之后。页面继续零运行依赖、零外部自动请求。
- 保留 560px 手机筛选与提示面板的原有行为阈值，补充 900px、600px 和 360px 布局调整。手机端恢复显示既有分类、角度标签和快捷键文字。
